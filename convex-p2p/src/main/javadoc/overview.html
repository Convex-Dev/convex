Convex P2P

Core peer-to-peer lattice functionality for Convex, building on the lattice data structures of convex-core and the NodeServer binary networking of convex-peer.

This module is infrastructure: it answers who is on the network, what they run and how to reach them. Applications such as convex-social are its users, but they do not each bring their own node server — P2PNode is the only one, and the regions it serves are a per-node choice rather than a per-build one. P2PLattice.NODE_ROOT is the default (infrastructure plus bundled applications); P2PLattice.ROOT is the same node with the application regions switched off, and is still a fully capable discovery node.

Key Types

  • convex.p2p.P2PLattice — the P2P root lattice, declaring the top-level :p2p (node registry), :id (user identity) and reserved :kad regions
  • convex.p2p.P2PNode — a peer-to-peer lattice node over that root
  • convex.p2p.P2PUser — a single user's owned area, with signing handled by the cursor chain
