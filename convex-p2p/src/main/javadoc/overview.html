Convex P2P

Rollup package for Convex P2P nodes, building on the lattice data structures of convex-core and the NodeServer binary networking of convex-peer.

One dependency gives a complete node. This module defines the P2P infrastructure regions — who is on the network, what they run, how to reach them — and bundles the application regions a node serves, so P2PNode is the only node server rather than one per application. Which rolled-up regions a node serves is a per-node choice: P2PLattice.NODE_ROOT is the default (infrastructure plus bundled applications), and P2PLattice.ROOT is the same node with the application regions switched off, still a fully capable discovery node.

Key Types

  • convex.p2p.P2PLattice — the P2P root lattice, declaring the top-level :p2p (node registry), :id (user identity) and reserved :kad regions
  • convex.p2p.P2PNode — a peer-to-peer lattice node over that root
  • convex.p2p.P2PUser — a single user's owned area, with signing handled by the cursor chain
